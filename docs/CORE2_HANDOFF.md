## Для PC2 / интегратора

1. **Таймаут frontend сейчас 45 секунд** (`src/services/analysis.ts`), а проверенный живой ответ занял 101 секунду. При интеграции увеличьте ожидание до 150 секунд и согласуйте браузерные тесты. Backend ограничивает ожидание OpenAI 120 секундами, без автоматических повторов.
2. Для пользовательских загрузок запускайте backend с `ANALYSIS_MODE=semantic` и `--env-file .env`. Явный query `mode=deterministic` и `/api/demo` сохраняют резервный путь без модели.
3. Отдельное заключение модели находится в `summary.analytical_note`, источники — в `summary.note_evidence`, статус — в `summary.note_verification_status`. Текущий адаптер checkpoint-1 эти поля не отображает. Сохраняйте источники и статус при подключении к существующему разделу заключения.
4. Коды ошибок остаются в `error.code`, безопасное описание — в `error.message`; перечень в [API.md](API.md). Ошибка модели не подменяется успешным ответом другого режима.

Frontend, `main` и ветка PC2 этим изменением не модифицированы. Для следующего checkpoint нужны проверки frontend, production build и браузерный end-to-end с семантическим backend.
