# CORE4: контроль ложных выводов

Основа — `integration/checkpoint-3`, `d3dd502`. Изменения только backend, его регрессионных тестов и этой документации. API-контракт сохранён; `analysis_id` использует версию `v3`.

## Воспроизведённые и исправленные причины

1. **Чужое сопоставление занимало сохранённую функцию.** Если одинаковая обязанность раньше была у двух подразделений, а после оставалась у одного, порядок обхода мог создать ложный перенос и пометить сохранённое назначение потерянным. Теперь точные совпадения у прежнего владельца резервируются первыми. При недостатке назначений объяснение отдельно допускает консолидацию, а не утверждает исчезновение функции.
2. **Контроль исполнения принимался за исполнение.** Подстроки «исполнение», «утверждённого бюджета» и отрицание «не утверждает» могли создавать неподтверждённый сигнал совмещения исполнения и контроля. Уточнены признаки действия и учёт непосредственного отрицания. Положительные примеры утверждения, исполнения и оплаты по-прежнему дают кандидата `NEEDS_REVIEW`.
3. **Запрет в единственном числе или внутри списка считался обычной функцией.** «Не имеет права», «не вправе», «запрещается» сохраняют тип `PROHIBITION`, включая отдельный подпункт внутри обычного списка. Следующие пункты не наследуют локальный запрет.

Это ограниченные исправления правил, а не универсальный разбор русской грамматики. Сложные отрицания, вложенные действия и неоднозначные владельцы по-прежнему требуют экспертной проверки.

## Проверки

Добавлено 16 контрольных случаев. До исправлений 10 из первоначальных 15 случаев воспроизводили дефекты; после исправлений проходит вся дополненная батарея.

Все backend-тесты: **87 passed**, включая локальные документы организатора. Python compile, `pip check`, `git diff --check`: PASS. Отдельный настоящий Astra HTTP smoke: **PASS**, 34,4 секунды, 108 ссылок сверены с источниками; найдены все заранее объявленные изменения и заключение с источниками обеих редакций.

На локальных документах организатора сохранены все **450** ранее извлечённых записей функций/прав/запретов. Количество лексических кандидатов на перенос уменьшилось **12 → 10**: обязанности ДНМ `5.4.8` и ДККМ `5.5.14` теперь корректно сопоставляются с сохранёнными назначениями. Два слабых лексических сигнала конфликта, вызванных упоминанием утверждённого бюджета, исключены. Это не утверждение об отсутствии реальных конфликтов: семантический анализ и экспертная проверка остаются необходимыми.

Количество подразделений осталось 3 → 5. Состав извлечённых записей не менялся; существующие проверки явных владельцев `5.3.2.а` и `5.3.2.б` сохранены.

HTTP `scripts.smoke_known_answer` в deterministic-режиме проходит: создание подразделения, перенос, потенциальная потеря, дублирование, положительный пример конфликта, 69 проверенных ссылок. Обычные тесты не используют настоящий ключ. Живой semantic smoke запускается отдельно.

Локальные JSON сравнения находятся только в ignored `artifacts/`. Документы, ключи и результаты анализа с исходными цитатами в Git не добавляются.
